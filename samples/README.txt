# samples/

Sample attendance reports and the documents generated from them.

a_r_25.pdf    -> a_r_25_out.xlsx    (Type B: text PDF, written as Excel)
n_r_10_n.pdf  -> n_r_10_n_out.pdf   (Type A: scanned PDF, read with OCR)

The report type is detected from the column headers, not from the file name.
